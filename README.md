# 🤖 AI vs Human Image Classification

![Python](https://img.shields.io/badge/Python-3.9%2B-blue?style=for-the-badge&logo=python)
![TensorFlow](https://img.shields.io/badge/TensorFlow-2.20.0-orange?style=for-the-badge&logo=tensorflow)
![Flask](https://img.shields.io/badge/Flask-Web%20App-black?style=for-the-badge&logo=flask)

A powerful web application designed to detect whether an image was generated by artificial intelligence (AI) or captured by a human. Powered by Transfer Learning models (**ResNet50V2**) with high accuracy, and deployed using **Flask** and **Docker**.

## 🚀 Live Demo
Try the application live on Hugging Face Spaces:
**[View Demo App](https://huggingface.co/spaces/merkuribingung/AI-or-Human-Generated-Classification-Image)**

---

## 📋 Features

* **🔍 Dual Detection Support**:
    * **File Upload**: Analyze images directly from your device.
    * **Instagram Integration**: Input an Instagram post URL to analyze the image directly (powered by `instaloader`).
      
* **🧠 Deep Learning Core**: Uses Transfer Learning with state-of-the-art architectures (ResNet50V2) for high accuracy.
* **📊 Detailed Analysis**: Provides probability scores (confidence level) for both AI and human predictions.
* **🎨 Modern UI**: Responsive interface with light and dark mode, and real-time scanning animations.
* **🐳 Dockerized**: Fully containerized for easy deployment on Hugging Face or any cloud/hosting provider.

---

## 🛠️ Tech Stack

* **Backend**: Python, Flask, Gunicorn

## 💻 Installation & Local Setup

Follow these steps to run the project locally on your machine.

### 1. Clone the Repository
First, download the source code from GitHub:
```bash
git clone https://github.com/mewcurryy/AI-or-Human-Generated-Classification-Image.git
cd AI-or-Human-Generated-Classification-Image
```

### 2. Set Up Virtual Environment (Recommended)
It is best practice to use a virtual environment to avoid conflicts with other projects.

**Windows:**
```bash
python -m venv venv
venv\Scripts\activate
```

**Mac/Linux:**
```bash
python3 -m venv venv
source venv/bin/activate
```

### 3. Install Dependencies
Install all required libraries (Flask, TensorFlow, Instaloader, etc.) using `requirements.txt`:
```bash
pip install -r requirements.txt
```

### 4. Setup Model File
⚠️ **Important:** Because the model file is large, you must ensure the `.keras` model is present.
1. Download or place your trained model (e.g., `ResNet50V2-AIvsHumanGenImages-Final.keras`) inside the `models/` folder.
2. If you don't have the model, you need to train it first or download it from the Releases/Hugging Face section.

### 5. Run the Application
Start the Flask server:
```bash
python main.py
```

After running the command, open your browser and go to:
👉 **[http://127.0.0.1:5000](http://127.0.0.1:5000)**

## 📖 Usage Guide

### Option 1: Upload an Image
1.  Click on the **"Upload Image"** box or drag & drop your file.
2.  Supported formats: `JPG`, `JPEG`, `PNG`.
3.  Click **"Analyze Image"**.
4.  The result will show the probability (e.g., *98% Human* or *99% AI*).

### Option 2: Instagram Analysis
1.  Copy the URL of a **Public Instagram post**.
2.  Paste the link into the **"Paste Instagram Link"** input field.
3.  Click **"Analyze Image"**.
4.  The app will extract the image and run the classification model instantly and show the probability.
